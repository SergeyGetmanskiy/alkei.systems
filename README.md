# Alkei.Systems

Корпоративный сайт Alkei.Systems: развитие бизнеса через управленческие решения,
продуктовый подход и технологии.

Стек: **React 18 + TypeScript + SCSS modules + Vite**, маршрутизация — `react-router-dom`.

## Запуск

```bash
npm install
npm run dev      # локальная разработка (http://localhost:5173)
npm run build    # проверка типов + production-сборка в dist/
npm run preview  # предпросмотр сборки
npm run typecheck
npm run verify   # типы + проверка локализаций + рендер всех маршрутов + сборка
```

## Проверки

| Команда | Что делает |
| --- | --- |
| `npm run typecheck` | проверка типов TypeScript (`tsc --noEmit`) |
| `npm run check:i18n` | сверяет набор ключей RU/KZ/EN — переводы не должны расходиться |
| `npm run check:render` | рендерит каждый маршрут и проверяет, что страница отрисовалась |
| `npm run verify` | всё вышеперечисленное плюс production-сборка |

Скрипты лежат в `scripts/` и запускаются из Node без дополнительных зависимостей
(используется `esbuild`, уже входящий в состав Vite).

## Структура

```

src/
├─ components/     переиспользуемые компоненты (Header, Footer, CTA, диалог связи, и т.д.)
```

## Хостинг

Сборка — статическая (`dist/`). Маршрутизация клиентская, поэтому
хостинг должен отдавать `index.html` для любого пути приложения.
Для Netlify/Cloudflare уже подготовлен `public/_redirects`
(`/* /index.html 200`). Для nginx понадобится аналогичный `try_files`.

В `src/config/site.ts` зафиксирован предполагаемый домен
`https://alkei.systems` — он используется в canonical, hreflang и sitemap.
Перед публикацией домен и корпоративную почту нужно подтвердить.

## Контент и локализация

Все тексты хранятся централизованно в `src/content/*.ts` и типизированы
интерфейсом `SiteContent` — набор ключей одинаков во всех языках.
Переключение языка сохраняет текущую страницу, если её перевод существует,
иначе пользователь попадает на главную выбранного языка.
URL казахской версии — `/kz/`, при этом в `hreflang` указан корректный
языковой тег `kk`.

Английская и казахская версии подготовлены как отдельные редакторские
переводы. До публикации их желательно проверить с носителем языка
(раздел 17 ТЗ, пункт 6).
